# Authenticated downloads are excluded

Bulk Whois and resources-without-valid-POCs downloads were removed from the
provider on September 24, 2026. Their data sources, client, configuration,
examples, probes and tests are no longer maintained. These services require
separate account approval and terms and are deliberately outside provider scope.
They are not remaining completion blockers.

The upstream reference documents remain in [the API archive](arin-api/README.md).
Public Whois-RWS and RDAP lookups remain supported. See the
[README exclusions](../../README.md) for configuration migration notes.
